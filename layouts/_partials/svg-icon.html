{{- /* Resolve an icon reference. Config carries no sprite `id`; the id is derived at build time and published in `` (default `static/svg/sprite_map.json`). This partial reads that map ONCE and caches it globally in hugo.Store, then turns a configured svg `path` into a `#` reference. Priority: 1. `path` found in the shared sprite map → "#" (relURL'd, uses the matching bundled sprite). 2. "svg/placeholder.svg" (universal default). Every returned value goes through relURL, so it resolves from any page depth (e.g. /posts/). Parameter (flat dict, e.g. a menu entry's `.Params.icon`): path (string): the icon's key relative to rootDir, e.g. "ui-oval/home-03.svg". This doubles as the shared sprite_map.json lookup key. Return: string $iconURL — for an inline ``, root-relative. */ -}} {{- $map := hugo.Store.Get "alice-sprite-map" -}} {{- if not $map -}} {{- $mapPath := "static/svg/sprite_map.json" -}} {{- $map = $mapPath | os.ReadFile | transform.Unmarshal -}} {{- hugo.Store.Set "alice-sprite-map" $map -}} {{- end -}} {{- $iconPath := .path -}} {{- $iconURL := "svg/placeholder.svg" | relURL -}} {{- $entry := index $map $iconPath -}} {{- if $entry -}} {{- $iconURL = printf "%s#%s" ((index $entry "sprite") | relURL) (index $entry "id") -}} {{- end -}} {{- return $iconURL -}}
