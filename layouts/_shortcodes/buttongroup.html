Usage: {{< buttongroup name="Actions" orientation="horizontal" >}} {{< button label="Save" type="primary" >}} {{< button label="Preview" >}} {{< button label="Cancel" >}} {{< /buttongroup >}} {{< buttongroup name="Drink" >}} {{< radio label="Coffee" checked=true >}} {{< radio label="Tea" >}} {{< radio label="Water" >}} {{< /buttongroup >}} The group renders a native
with an optional , so the controls share one accessible group title. It accepts `button`, `radio`, and `checkbox` children and lays them out in a column or a wrapping row. `name` is the visible group title, not a DOM id or form name: the fieldset id (default buttongroup-) seeds the default child ids, and the default native name of a radio/checkbox, when that child does not set its own. Args (all optional): name — visible group title, inline Markdown; rendered as the legend orientation — vertical|v (default) or horizontal|h size — default size for the children: small|s, medium|m, or large|l disabled — disable every child ariaLabel — accessible name when there is no visible title (default: "Button group") id — fieldset id (default buttongroup-); also the default child-id base and, for radio/checkbox children, their default native name class — extra classes on the fieldset Site defaults live under params.buttongroup (orientation, class); the child controls keep their site defaults under params.button, params.radio, and params.checkbox. Geometry, colors, and motion are --button-group-* variables in static/css/buttongroup.css. Hugo renders nested shortcodes before the parent, so the parent cannot hand computed state down to the children. Each child resolves the same group id from .Parent.Ordinal and reads the raw group arguments directly. A child's own `size` wins; group `disabled=true` disables every child. Group-level colors are not inherited because the three controls color different parts; set `tintColor` / `checkColor` / button type colors per child. The group has no group-level `js`: attach `js` to the individual button, radio, or checkbox that needs behavior. */ -}} {{- /* Site defaults.
