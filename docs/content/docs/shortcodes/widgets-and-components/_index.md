These pages document the theme's widgets and components. They include display
elements such as icons and labels, form controls, tabs, dropdowns, admonitions, details,
the carousel, and the code editor. Each component uses native HTML where
possible, so keyboard and screen-reader behavior stay intact, and every
component can be configured per use.
