You can use `{{</* loremipsum */>}}` to generate placeholder text.

{{< loremipsum >}}

You can also specify the number of parapraghs (n) generated by `{{</* loremipsum paragraphs=n */>}}`,
by default n equals to 1.

{{< loremipsum paragraphs=2 >}}
