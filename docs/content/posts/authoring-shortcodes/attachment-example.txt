Alice theme — Attachment shortcode example
==========================================

This text file is a page resource of "Alice (3): Authoring Shortcodes".
The attachment shortcode in that post links here and advertises this
file's size before you click it.

The size comes from the resource's byte length and scales automatically:
values below 1 KB stay in B, then the shortcode moves through KB, MB,
and GB in 1024-byte steps, keeping one decimal place.
